Reconciliation Logic & Compliance

How secure is this portal?

All reconciliation computations and Excel parsing processes run entirely within your browser window. No information is transmitted to external servers, protecting critical corporate financial and employee data.

What happens to unmatched names?

Unmatched rows with no matching IDs are highlighted in bright red inside the exported final submission file, allowing your accounts team to locate and input missing IDs manually.

Matching priority parameters

The engine first attempts matching via ID columns (National ID / SSNIT ID) if mapped in both files. If those fields are absent or mismatch, it falls back to fuzzy and soundex string-matching permutations.

Compatible runtimes

The application has been verified to run optimally on modern browsers including Chrome, Edge, Firefox, and Safari with JavaScript and DOM operations enabled.
